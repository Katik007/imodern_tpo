# Запуск автотестов iModern на Windows

Для показа всего набора дважды нажмите `show_all_tests.cmd` или выполните команду ниже в PowerShell из папки проекта.

```powershell
Set-Location -LiteralPath 'C:\Users\User\Desktop\тпо_2'
.\run_tests.cmd --headed
```

Действия в браузере замедлены. Результат виден 2,5 секунды, при падении — 8 секунд, последняя страница остаётся на 12 секунд. После прогона откроется Allure. Его можно также открыть вручную через `allure-report/index.html`. В разделе **Suites** откройте **AUTH-08** для показа упавшего шага и снимка страницы.

Для показа на защите дважды нажмите `show_phone_demo.cmd`. В Chromium будет видна попытка входа по телефону и ответ iModern. Демонстрация показывает только этот сценарий, оставляет ошибку на экране на несколько секунд и сохраняет два снимка в `test-results/phone-demo/`.

1. Установите Python 3.10+ и Java 8+, если их ещё нет. Для первого запуска нужен интернет.
2. Откройте папку проекта и дважды нажмите `run_tests.cmd`.
3. После завершения скрипт откроет `allure-report/index.html`. Краткие результаты находятся в `test-results/summary.md`.

Варианты из PowerShell в папке проекта.

| Команда | Что запускает |
|---|---|
| `.\run_tests.cmd --headed` | Весь прогон с видимым браузером |
| `.\run_tests.cmd --suite auth` | Только проверки входа |
| `.\run_tests.cmd --suite shop` | Только путь от поиска до формы заказа |
| `.\run_tests.cmd --no-open` | Весь прогон с сохранением отчёта |

Реквизиты аккаунта для проверок с существующим пользователем задаются только в локальном `.env`. Имена переменных и настройки времени ожидания приведены в `.env.example`. При передаче проекта исключите `.env`, `.venv` и `.test-runtime`. HTML-отчёт открывается отдельно в браузере.
